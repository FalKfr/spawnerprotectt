SPAWNER PROTECT (Fabric client mod, Minecraft 26.2)

BUILD WITHOUT INSTALLING ANYTHING
1. Create a new GitHub repo and upload everything in this folder (including the .github folder).
2. Open the Actions tab, let "Build Spawner Protect" run (or click Run workflow).
3. Download the "spawnerprotect-jar" artifact. It contains the .jar.

BUILD LOCALLY
Needs JDK 25 and Gradle 9.5+. Run:  gradle build
The mod is build/libs/spawnerprotect-1.0.0.jar (NOT the -sources jar).

INSTALL
Put the jar in .minecraft/mods with Fabric API for 26.2, using Fabric Loader 0.19+ and Java 25.

USE
Press P in-game to turn Spawner Protect ON or OFF. Status shows top-left and on the action bar.
Rebind it in Options > Controls > Key Binds > Spawner Protect.
