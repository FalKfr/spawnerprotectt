SPAWNER PROTECT (Fabric client mod, Minecraft 1.21.11)

Needs a SILK TOUCH PICKAXE in your hotbar.
When another player is detected near you and a skeleton spawner is in range, it holds shift and
breaks the spawner. Press P to turn it ON/OFF (status shows top-left).

SETTINGS (Mod Menu -> Spawner Protect -> settings icon)
- Auto detect ON : keeps breaking until no players are detected anymore (then stops, stays online).
                   If every spawner is gone it logs you off.
- Auto detect OFF (manual): breaks exactly N times (4 stacked spawners = 4 breaks), then logs off.

INSTALL: Fabric Loader 0.18+, Fabric API for 1.21.11, Mod Menu 17+ (optional, for the settings screen), Java 21.
